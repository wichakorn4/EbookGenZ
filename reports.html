📈 1. ยอดขายตามช่วงเวลา (Sales Over Time)

แสดงยอดขายรวม จำนวนคำสั่งซื้อ และค่าเฉลี่ยต่อบิล จำแนกตามวันที่หรือเดือน

GROUP BY / SUM
วันที่ / ช่วงเวลา จำนวนคำสั่งซื้อ ยอดขายรวม (บาท) ค่าเฉลี่ยต่อบิล (บาท)
2026-09-27 12 ออเดอร์ ฿3,850 ฿320.83
2026-09-26 18 ออเดอร์ ฿5,920 ฿328.88

-- SQL Query:

SELECT DATE(created_at) AS sale_date, COUNT(order_id) AS total_orders, SUM(total_amount) AS total_sales, AVG(total_amount) AS avg_order_value FROM orders WHERE order_status = 'confirmed' GROUP BY DATE(created_at);

🔥 2. E-Book ขายดีสูงสุด (Top Best-Selling)

จัดอันดับหนังสือดิจิทัลที่มียอดขายสูงสุดตามจำนวนเล่มและรายได้รวม

JOIN / LIMIT
อันดับ ชื่อหนังสือ ผู้แต่ง ขายได้ (เล่ม) รายได้รวม (บาท)
#1 Clean Code ฉบับปรมาจารย์ Robert C. Martin 45 เล่ม ฿15,750
#2 Java Object-Oriented Mastery Somchai Tech 32 เล่ม ฿9,280

-- SQL Query:

SELECT e.title, SUM(oi.quantity) AS total_sold, SUM(oi.price * oi.quantity) AS total_revenue FROM order_items oi JOIN ebooks e ON oi.ebook_id = e.ebook_id GROUP BY e.ebook_id ORDER BY total_sold DESC LIMIT 5;

📂 3. ยอดขายตามหมวดหมู่ (Sales by Category)

วิเคราะห์ว่าหมวดหมู่หนังสือใดสร้างยอดขายสูงสุด

JOIN Multi-Tables
หมวดหมู่ จำนวนเล่มที่ขายได้ ยอดขายรวม (บาท)
Programming & Tech 77 เล่ม ฿25,030
Business & Marketing 30 เล่ม ฿7,470

-- SQL Query:

SELECT c.category_name, SUM(oi.quantity) AS total_items, SUM(oi.price * oi.quantity) AS category_sales FROM order_items oi JOIN ebooks e ON oi.ebook_id = e.ebook_id JOIN categories c ON e.category_id = c.category_id GROUP BY c.category_id;

👤 4. ลูกค้าและคำสั่งซื้อ (Customer Analysis)

วิเคราะห์ลูกค้ารายที่มียอดซื้อสะสมสูง

HAVING / COUNT
ชื่อลูกค้า จำนวนออเดอร์ ยอดซื้อสะสม (บาท)
คุณลูกค้า ทดสอบระบบ 8 ออเดอร์ ฿3,250

-- SQL Query:

SELECT u.full_name, COUNT(o.order_id) AS order_count, SUM(o.total_amount) AS total_spent FROM orders o JOIN users u ON o.user_id = u.user_id GROUP BY u.user_id HAVING SUM(o.total_amount) > 1000 ORDER BY total_spent DESC;
